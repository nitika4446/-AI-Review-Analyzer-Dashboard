# 🤖 AI Review Analyzer Dashboard

An end-to-end NLP project that analyzes customer reviews using NLP and Machine Learning.

---

## 🚀 Features

✅ Sentiment Analysis  
✅ BERT-Based Review Classification  
✅ Keyword Extraction  
✅ AI Text Summary  
✅ Interactive Plotly Charts  
✅ CSV Export  
✅ Streamlit Dashboard UI  

---

## 🛠 Tech Stack

- Python
- Streamlit
- NLP
- Transformers
- KeyBERT
- Plotly
- TextBlob
- Scikit-learn

---

## 📂 Project Structure

AI_Review_Analyzer/
│
├── app.py
├── requirements.txt
├── reviews_data.csv
└── README.md

---

## ▶ Run Project Locally

```bash
pip install -r requirements.txt
streamlit run app.py
````

---

## 📊 Dataset

Place your dataset file as:

```txt
reviews_data.csv
```

inside the project folder.

---

## 🌐 Deploy on Streamlit Cloud

1. Upload project to GitHub
2. Open Streamlit Cloud
3. Connect GitHub repository
4. Select app.py
5. Deploy
